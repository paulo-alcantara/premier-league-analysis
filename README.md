# Premier League Performance Analysis

## About the Project

This project aims to analyze the performance of
the 20 teams competing in the English Premier League
during the 2024/2025 season.

The analysis focuses on offensive performance,
defensive performance, home and away performance,
and relationships between match statistics.

## Objectives

- Analyze the overall performance of each team.
- Compare offensive and defensive indicators.
- Investigate home and away performance.
- Explore relationships between match statistics.
- Identify relevant patterns and insights.

## Dataset

Source: Football-Data.co.uk

League: English Premier League

Season: 2024/2025

Matches: 380

Teams: 20

Dataset: E0.csv

Source website:
https://www.football-data.co.uk/

Note: Consult the dataset provider's terms of
use before redistributing data.

## Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Enter the project directory:

    cd premier-league-analysis

Create a virtual environment:

    python -m venv .venv

Activate the environment:

    source .venv/bin/activate

Install dependencies:

    pip install -r requirements.txt
